# NeoLume

Ελληνικό / αγγλικό στατικό site με πραγματική WebGL προβολή από τα πέντε STL του προϊόντος. Δεν απαιτεί npm, build ή πληρωμένο server.

## Τρέχουσα έκδοση

- Τιμή προϊόντος: 25 €. BOX NOW: 3 € ανά αποστολή. Ένα προϊόν: 28 €, δύο: 53 €.
- Instagram: https://www.instagram.com/neolume_official/
- Δοκιμαστικό email: hello@neolume.example. Το `.example` είναι ενδεικτικό και δεν χρησιμοποιείται για αποστολή.
- Η φόρμα δημιουργεί προεπισκόπηση αιτήματος με δυνατότητα αντιγραφής. Δεν αποθηκεύει στοιχεία σε server, δεν στέλνει email μόνη της και δεν χρεώνει χρήματα.
- IRIS και Revolut είναι επιλογές του αιτήματος, όχι συνδεδεμένες πύλες πληρωμής. Δεν υπάρχει αυτόματη επιβεβαίωση κατάθεσης.
- Η συναρμολόγηση των STL είναι προσεγγιστική: 16 επαναλήψεις του Sheets, βήμα 10,5 μονάδων και τοποθέτηση των εξαρτημάτων σύμφωνα με τις φωτογραφίες. Χρειάζεται επιβεβαίωση από τον κατασκευαστή. Δεν παρουσιάζονται υποτιθέμενες διαστάσεις ως τεχνική προδιαγραφή.

## Τοπική προεπισκόπηση

Με Python, από αυτόν τον φάκελο:

```powershell
python -m http.server 4174 --bind 127.0.0.1
```

Άνοιγμα: http://127.0.0.1:4174

Το χωριστό αρχείο `NeoLume-preview.html` ανοίγει απευθείας με διπλό κλικ σε browser, χωρίς server. Είναι αυτοτελές αντίγραφο προεπισκόπησης· οι αλλαγές γίνονται στα αρχεία αυτού του φακέλου.

## GitHub + Cloudflare Pages

1. Δημιούργησε λογαριασμό στο https://github.com/signup και στο https://dash.cloudflare.com/sign-up.
2. Στο GitHub, δημιούργησε repository `neolume`. Μπορεί να είναι private. Ανέβασε τα περιεχόμενα αυτού του φακέλου στη ρίζα του repository, ώστε το `index.html` να είναι στη ρίζα.
3. Στο Cloudflare Pages, σύνδεσε το repository μέσω Git integration.
4. Επίλεξε branch `main`, χωρίς framework. Build command: `exit 0`. Build output directory: `.` (η ρίζα του repository). Δεν χρειάζονται environment variables.
5. Το Cloudflare δίνει διεύθυνση `*.pages.dev`. Κάθε αλλαγή που αποθηκεύεται στο συνδεδεμένο branch ενημερώνει το site.

Δεν χρησιμοποιούμε GitHub Pages για το εμπορικό site. Το repository στο GitHub φιλοξενεί τον κώδικα και το Cloudflare Pages φιλοξενεί την ιστοσελίδα. Προαιρετικό δικό σου domain αγοράζεται χωριστά· το δωρεάν υποdomain αρκεί για αρχή. Ισχύουν τα όρια του δωρεάν προγράμματος.

Επίσημη τεκμηρίωση:
- https://developers.cloudflare.com/pages/framework-guides/deploy-anything/
- https://developers.cloudflare.com/pages/configuration/git-integration/
- https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits

## Ενεργοποίηση πραγματικών αιτημάτων

Στο `config.js`, αντικατάστησε το email με το πραγματικό και όρισε `demo: false` μόνο όταν είσαι έτοιμος. Η αποστολή χρησιμοποιεί το πρόγραμμα email του επισκέπτη και απαιτεί από εκείνον να πατήσει Αποστολή. Για απευθείας υποβολή μέσα στο site χρειάζεται backend ή υπηρεσία φορμών.

Για πραγματικές πωλήσεις εκκρεμούν τα στοιχεία πληρωμής IRIS/Revolut, τα πραγματικά στοιχεία πωλητή και το εγκεκριμένο περιεχόμενο για όρους αγοράς, επιστροφές και ιδιωτικότητα. Δεν έχουν επινοηθεί. Το τρέχον site είναι demo με επικοινωνία μέσω Instagram.

## Αρχεία

- `index.html`: σελίδα και περιεχόμενο.
- `style.css`: responsive σχεδίαση.
- `app.js`: δύο γλώσσες, επιλογές χρωμάτων, φόρμα και υπολογισμός συνόλου.
- `viewer.js`: WebGL renderer, φωτισμός, περιστροφή, συναρμολόγηση.
- `config.js`: δημόσια στοιχεία επικοινωνίας, demo mode και τιμές.
- `lamp.json`: τρίγωνα και normals από τα STL, χωρίς εξάρτηση βιβλιοθήκης.
- `*.jpg`: φωτογραφίες προϊόντος από τον χρήστη.

Οι γραμματοσειρές Google Fonts είναι προαιρετικές: υπάρχει fallback σε τοπική γραμματοσειρά. Δεν υπάρχει analytics ή διαφημιστική παρακολούθηση. Το localStorage χρησιμοποιείται μόνο για την προτίμηση γλώσσας.

## Έλεγχοι που έγιναν

JavaScript syntax, HTTP 200, πραγματική φόρτωση WebGL, εναλλαγή γλώσσας και χρωμάτων, διακόπτης φωτός, δοκιμαστικό αίτημα με δύο τεμάχια/Revolut και σύνολο 53 €, απουσία browser console errors. Έλεγχος mobile viewport χωρίς οριζόντια υπερχείλιση. Δεν έγινε πραγματική πληρωμή ή αποστολή email.
